สั่งพิมพ์ใน 3 ขั้น ไม่ต้องส่งไฟล์ทางแชต ไม่ต้องรอร้านตอบราคา

  1. เลือกบริการและไฟล์ขาวดำ สี หรือรูปถ่าย เลือกไฟล์ PDF แล้วระบบนับหน้าให้เอง
  2. ดูราคาแล้วส่งงานราคาขึ้นทันทีตามจำนวนหน้า ชุด และงานเก็บเล่ม ใส่โค้ดส่วนลดได้
  3. มารับและจ่ายที่ร้านมีแจ้งเตือนเมื่อร้านรับงาน กำลังพิมพ์ และงานพร้อมรับ

คำถามที่พบบ่อย ดูราคาและโค้ดส่วนลด

ส่งไฟล์แบบไหนได้บ้าง

PDF, JPG และ PNG ถ้าเป็น PDF ระบบนับหน้าให้เองตอนเลือกไฟล์ ไฟล์จะไม่ถูกส่งขึ้นระบบ ให้แนบลิงก์ เช่น Google Drive หรือนำไฟล์มาที่ร้าน

จ่ายเงินตอนไหน

จ่ายที่ร้านตอนมารับงาน ด้วยเงินสด โอนเงิน หรือ QR พร้อมเพย์ ไม่ต้องจ่ายล่วงหน้า

ยกเลิกงานได้ถึงเมื่อไหร่

ยกเลิกเองได้ในหน้ารายละเอียดงาน จนกว่าร้านจะกดรับงาน หลังจากนั้นต้องติดต่อร้าน

โค้ดส่วนลดใช้ได้กี่ครั้ง

แต่ละโค้ดใช้ได้คนละ 1 ครั้ง มีหลายโค้ดก็ใช้ได้ทุกโค้ด ถ้างานที่ใช้โค้ดถูกยกเลิก จะได้สิทธิ์โค้ดนั้นคืน

พิมพ์สีเยอะ ๆ มีส่วนลดไหม

พิมพ์สีเกิน 50 หน้าต่อชุด ลดค่าพิมพ์ให้ 10% อัตโนมัติ และยังใช้โค้ดส่วนลดร่วมได้

จะรู้ได้ยังไงว่างานเสร็จแล้ว

มีแจ้งเตือนในเว็บทุกครั้งที่ร้านเปลี่ยนสถานะ เมื่อขึ้นว่า "พร้อมรับงาน" มารับได้เลย

ดูสีก็รู้ว่างานถึงไหน
